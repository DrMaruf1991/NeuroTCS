# Web layer for the NeuroTCS live demo.
#
# The AUDIT ENGINE (neurotcs==1.85.1) is NOT pinned here on purpose: it is
# installed from THIS repo's source so the App Service runs the EXACT shipped
# engine whose invariants the demo reproduces (see demo/startup.sh, which runs
# `pip install .` at the repo root first). Installing neurotcs from a public
# index instead would risk a different build than the one the cTCS is locked to.
#
# These web deps do not affect cTCS (they are transport only) but are pinned for
# a reproducible web layer.

uvicorn[standard]==0.49.0
