NeuroTCS Live Audit

Reproducible, citation-locked auditor of Alzheimer’s-disease cohort staging trajectories.

connecting…

This page runs real audits of five public AD cohorts on this private server, live, through the shipped NeuroTCS engine. NeuroTCS is an auditor, not a measurement tool: it checks whether each cohort’s CN → MCI → AD trajectories obey published staging criteria (NIA-AA 2018) and emits a consistency score (cTCS), flagged transitions, and a byte-deterministic audit id. It never measures, segments, or diagnoses.

Cross-cohort cTCS

Consistency score with 95% CI whiskers. Higher = fewer inadmissible transitions. The spread is real and explainable — A4 is preclinical (mostly CN), MIRIAD is MMSE-staged (coarser).

Audit your own file

Upload a staging table (.xlsx or .csv) with a subject id, a diagnosis/state column, and — optionally — a visit date. NeuroTCS auto-suggests the column mapping; you confirm it, then it runs the same audit engine the cohorts use and returns the cTCS, flagged transitions, and an audit_id. The file is processed in memory only — never written to disk, discarded when the audit returns.

Why this is reproducible

＝

Same input → same audit id

The audit_id is a SHA-256 over the audited trajectories and the rule pack. Re-run on the same data and it is byte-for-byte identical — the proof of reproducibility.

§

Rules cite published criteria

Every admissibility rule traces to a specific paper by PMID / DOI. A result means “checked against these exact cited rules.”

#

IDs are hashed, data stays home

The browser receives results only — scores, counts, citations, and a hashed audit id. Raw records and subject ids never leave the private server.

✓

Parity with the CLI, proven

Each live result is checked against the locked cTCS/counts already proven via the CLI (demo/test_web_parity.py), to tolerance 0.0005 on cTCS and exactly on the counts.

NeuroTCS audits pre-existing staging data against cited published criteria. No measurement, no inference, no LLM. Results shown are de-identified aggregates.
